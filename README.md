# docs.madeformeai.com

A private customer reference for people Quick IT Projects has already set up. It is not indexed and not linked from the public sites; send customers a direct link to the page they need.
Tabs (docs.json): Start Here, What I Build, Market Forge, MindMap.
Pages are Mintlify MDX with YAML frontmatter. Follow STYLE-CONTRACT.md for every page.
To edit: change the .mdx, preview with `mint dev`, check links with `mint broken-links`.
Pushing `main` deploys the live site.
Run `bash scripts/docs-leak-scan.sh` before every push, it must print CLEAN.
No em dashes anywhere.
