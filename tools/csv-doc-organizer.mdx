Paste any mess: notes, a mangled export, table-ish junk. Get a clean file back. Three output modes, one paste.

## The three modes

- **CSV**: a clean, valid CSV with sensible column headers, one record per row, properly quoted. Ready to import into a spreadsheet or any system that kept rejecting the original.
- **Table**: a clean Markdown table with a title, for when the destination is a doc or a wiki, not a spreadsheet.
- **Document**: your raw text rewritten as a clean, structured document with a title and sections. Same meaning, actual structure.

## The rules it follows

This tool is deliberately boring, which is what you want from a data cleaner:

- **It never invents data.** If a value isn't in your paste, it doesn't appear in the output.
- **It never changes meaning.** Document mode restructures, it doesn't rewrite your intent.
- **Output is the file, period.** No commentary, no "here's your data!", no code fences to strip. You get the clean result and a download.

## What people throw at it

Exports that won't re-import anywhere. Meeting notes that were secretly a table the whole time. Copy-pasted email chains that need to become a list. The contact dump from that one system that quotes nothing and delimits randomly. Paste, pick a mode, download.
