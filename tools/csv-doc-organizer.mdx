---
title: "Clean up a paste"
description: "Paste messy notes or a broken export and get a clean CSV, table, or document back"
---

When you are done, you have a clean file built from whatever you pasted: a valid
CSV, a Markdown table, or a structured document. Nothing in it that was not in your
paste.

## Steps

<Steps>
  <Step title="Open the Tools tab on your dashboard and pick CSV / Doc Organizer">
  </Step>
  <Step title="Paste the mess into the box">
    Notes, a mangled export, table-ish text, a copied email chain, a contact dump
    with random delimiters. Any of it.
  </Step>
  <Step title="Pick an output mode">
    - **CSV**: a valid CSV with sensible column headers, one record per row,
      properly quoted. For a spreadsheet or a system that rejected the original.
    - **Table**: a Markdown table with a title. For a doc or a wiki.
    - **Document**: your text rewritten as a structured document with a title and
      sections. Same meaning, with structure.
  </Step>
  <Step title="Download the result">
    The output is the file and nothing else. No commentary, no code fences to strip.
  </Step>
</Steps>

<Note>
It never invents data. If a value is not in your paste, it is not in the output.
Document mode restructures; it does not change what you meant.
</Note>

## If this fails

- Columns come out wrong in CSV mode -> add a first line to your paste that names the columns, then run it again.
- The download opens as text instead of saving -> right-click the download and choose **Save link as**, or paste the output into a new file yourself.
- A value looks changed -> compare it against your paste; the tool does not add or rewrite values, so the difference is usually quoting or whitespace.
- Still stuck: email support@madeformeai.com with a screenshot and the time it happened.
