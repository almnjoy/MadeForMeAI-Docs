## Steps

<Steps>
  <Step title="Open the Tools tab on your dashboard and pick Website Builder">
  </Step>
  <Step title="Describe the page in plain language">
    For example: a landing page for a lawn care business, friendly, three services,
    a call button. The more specific the brief, the sharper the page.
  </Step>
  <Step title="Pick a style from the grid">
    Each preset is a full design direction, from clean and corporate to warm and
    editorial to a terminal look.
  </Step>
  <Step title="Preview it">
    The page renders live on screen.
  </Step>
  <Step title="Download it, or change the brief and go again">
    Download gives you one HTML file with all the styling inside it. Web fonts are
    the only outside dependency. If you want something different, edit the
    description or pick another style and build again.
  </Step>
</Steps>

<Note>
Good fits: a landing page before the full site exists, an event page, a one-page
portfolio or link hub, or a quick mock to show someone a direction.
</Note>

## If this fails

- The page looks generic -> add specifics to the brief: the business name, the three things you offer, what the button should say.
- The preview does not render -> reload the tool and build again; if it still fails, try a different style preset.
- The downloaded file opens without styling -> make sure you are online the first time you open it, since fonts load from the web.
- Still stuck: email support@madeformeai.com with a screenshot and the time it happened.
