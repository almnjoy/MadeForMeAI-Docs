Every route ends at the same place: the desk open in paper mode, with your keys on
your own machine.

## One codebase, two ways to install it

There is no "app version" and "open-source version" - the app **is** the repo,
built. Same code, same MIT licence, same features.

| | What you do | Platform |
|---|---|---|
| **The app** | download, unzip, double-click | **Windows** |
| **From source** | clone and run it | Windows, macOS, Linux |

Windows-only for the download is a property of the build tool, not a decision:
PyInstaller builds for the operating system it runs on. Nothing is missing on
macOS or Linux, you just install it the developer way.

<Note>
The Windows app is being packaged now. Until the first release lands, use one of
the source options below - they are what the app runs internally anyway.
</Note>

## Option 0: the app (Windows)

Grab the newest `MarketForge-win64.zip` from
[Releases](https://github.com/almnjoy/MarketForge/releases/latest), unzip it
anywhere, and run `MarketForge.exe`. No Python, no terminal, no git.

First launch walks you through your Alpaca paper keys. It ships in paper mode with
auto-trading off, and going live is a deliberate, separate act - see
[rules and risk](/marketforge/rules-and-risk).

## Option 1: one line

<Tabs>
  <Tab title="Windows">
    ```powershell
    powershell -c "irm https://madeformeai.com/marketforge/install.ps1 | iex"
    ```
  </Tab>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://madeformeai.com/marketforge/install.sh | bash
    ```
  </Tab>
</Tabs>

It clones the repo to your home folder, installs the one dependency, creates your
config file, and opens the folder. Run it again later and it updates in place.

## Option 2: let your AI agent do it

Paste this to Claude Code, Codex, Cursor, or whatever you run. It installs the desk,
sets up your keys **with** you, and then learns your trading plan.

```text
Set up Market Forge - the open-source AI trading desk - on this machine.
Repo: https://github.com/almnjoy/MarketForge

1. Check for git and Python 3.10+; help me install whichever is missing.
2. Clone the repo to my home directory.
3. Install the one dependency: python -m pip install -r requirements.txt
4. Copy bot/.env.template to bot/.env, then ask me for my Alpaca PAPER keys
   (free at alpaca.markets) and fill them in. Keep STOCK_ENV=paper and leave
   every auto-trading flag false.
5. Launch it (run-portable.bat on Windows, else MF_EMBEDDED=1 python app.py)
   and confirm http://localhost:8410 loads with PAPER in the header.
6. Read PORTABLE.md and CLAUDE.md, then walk me through the RULES tab and
   memory.md so the desk learns MY plan.

Hard rules for you: never enable live trading, never place a trade, never
change risk settings without my explicit instruction.
```

## Option 3: by hand

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone https://github.com/almnjoy/MarketForge
    cd MarketForge
    pip install -r requirements.txt
    ```
  </Step>
  <Step title="Run the guided setup">
    ```bash
    python setup.py
    ```
    It checks your Python, takes your Alpaca keys and **validates them against the
    API**, detects whether your account has real-time data, asks how you plan to use
    it, and writes `bot/.env` for you.

    Re-run it any time - it shows your current settings and lets you keep them.
  </Step>
  <Step title="Launch">
    Windows: double-click **`run-portable.bat`**.

    macOS / Linux: `MF_EMBEDDED=1 python app.py`

    Then open [http://localhost:8410](http://localhost:8410).
  </Step>
</Steps>

## What setup asks you

<AccordionGroup>
  <Accordion title="Paper or live account" icon="building-columns">
    Paper is the default and the right answer to start. Paper and live keys are
    different pairs and live in different settings, so one can never be used as the
    other.
  </Accordion>
  <Accordion title="Your keys - which it then tests" icon="key">
    Setup calls the Alpaca account endpoint with what you typed. If the keys are wrong
    or from the wrong dashboard, you find out immediately instead of at first launch.
  </Accordion>
  <Accordion title="Nothing - it detects your data feed" icon="bolt">
    It asks Alpaca whether your account can read recent SIP data. Entitled accounts get
    **real-time**; everyone else gets the free IEX feed. No question to answer, no
    subscription page to go read.
  </Accordion>
  <Accordion title="How you will use it" icon="sliders">
    - **Research only** - radar, charts, chatter, copilot. No trading at all.
    - **Research + manual trades** - you pull the trigger from the ticket.
    - **Small automatic entries** - hard-capped, trailing stop on every entry.

    Whatever you pick is shown in the dashboard header, so the desk never leaves you
    guessing about what it is allowed to do.
  </Accordion>
  <Accordion title="Optional scoring and alerts" icon="microchip">
    Whether to enable LLM catalyst scoring (and where your model lives), and a Discord
    webhook if you want radar hits on your phone. Both can be skipped and added later.
  </Accordion>
</AccordionGroup>

## Getting Alpaca paper keys

<Steps>
  <Step title="Sign up">
    Create a free account at [alpaca.markets](https://alpaca.markets).
  </Step>
  <Step title="Switch to the paper dashboard">
    There is a toggle between Live and Paper. Choose **Paper** - fake money, real
    market data.
  </Step>
  <Step title="Generate a key">
    In the API Keys panel, generate a key. You get an ID and a secret, and the secret
    is shown **once**. Paste both into `bot/.env` immediately.
  </Step>
</Steps>

<Warning>
Paper and live keys are different pairs. Market Forge keeps them in separate settings
on purpose, so a paper key can never place a live order by accident.
</Warning>

## First launch checklist

You should see, top to bottom:

- The Market Forge logo, then a **PAPER** badge
- A scrolling ticker of index and megacap prices
- Equity and cash matching your Alpaca paper balance
- Tabs: OVERVIEW, CATALYST_RADAR, RETAIL_RADAR, WORKBENCH, RULES, JOURNAL, COPILOT

If the radar is empty, that is normal outside market hours. Scans run at 10am, noon,
2pm, and 4pm ET on weekdays. You can force one with the **Re-scan** button.

## Turning on the copilot

Open a terminal in the Market Forge folder and start your agent there (for Claude
Code, just run `claude`). It reads `CLAUDE.md` on its own and becomes your desk
copilot. Now anything you type in the COPILOT tab gets answered automatically, and
you can ask it to build boards for you.
