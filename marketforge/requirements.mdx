Market Forge is light. Two required tools, one pip install, one free account, and a
short list of optional extras that each unlock one feature.

## Required

<CardGroup cols={2}>
  <Card title="Python 3.10 or newer" icon="python" href="https://python.org">
    On Windows, tick **Add Python to PATH** during install. Or skip Python entirely
    with the Windows app; see [install](/marketforge/install).
  </Card>
  <Card title="Git" icon="code-branch" href="https://git-scm.com">
    Used to install and update. The one-line installer needs it.
  </Card>
  <Card title="One pip install" icon="box">
    `pip install -r requirements.txt`. The installer and the agent path run it for you.
  </Card>
  <Card title="An Alpaca account" icon="building-columns" href="https://alpaca.markets">
    Free. **Paper** keys are all you need to start; they are separate from live keys
    and use fake money against real market data.
  </Card>
</CardGroup>

<Note>
That is the entire required list. No Docker, no database, no Node, no cloud account.
</Note>

## Optional, and what each one buys you

<AccordionGroup>
  <Accordion title="An AI coding agent - unlocks the copilot" icon="robot">
    **Claude Code**, Codex, or any agent that can read and write files in a folder.

    Without it the dashboard still works as a scanner and manual trading surface. With
    it, the COPILOT tab comes alive: it answers you in chat, builds live panels on the
    Workbench, explains your risk knobs, and replays your trading day.

    The same agent also scores radar catalysts signal-vs-noise (0-100). No other
    install is needed for scoring. The model knob is `RADAR_AGENT_MODEL`.

    Market Forge talks to agents through plain files (`panels/`, `chat-*.jsonl`,
    `memory.md`, `journal.jsonl`), so it is not locked to one vendor.
  </Accordion>

  <Accordion title="Voicebox - unlocks a natural voice and offline voice input" icon="microphone">
    A local text-to-speech app: [voicebox.sh](https://voicebox.sh/). Point Market Forge
    at it and pick a **Kokoro** voice profile.

    Spoken replies then come out in that voice instead of the browser's built-in
    speech. Without Voicebox the copilot still talks, it sounds like a browser.
  </Accordion>

  <Accordion title="Chrome or Edge - unlocks browser voice input" icon="chrome">
    Push-to-talk and the hot mic use the browser's speech recognition, which ships in
    Chrome and Edge. Everything else works in any modern browser.
  </Accordion>

  <Accordion title="A Discord webhook - unlocks phone alerts" icon="discord">
    Add a webhook URL in `bot/.env` and scored catalysts get pushed to that channel,
    which is the simplest way to see radar hits on your phone.
  </Accordion>
</AccordionGroup>

## Market data: free versus real-time

Alpaca gives every account the free **IEX** feed. It is real quotes, but from one
exchange - a slice of total volume, so dollar-volume reads low and thin names look
thinner than they are.

If you pay Alpaca for market data, your account is entitled to the **SIP** feed: the
full consolidated tape across all exchanges, in real time.

<Note>
**You do not have to know which one you have.** `python setup.py` asks Alpaca directly
and writes the right value. Subscribe later, re-run setup, and it switches you over.
</Note>

The dashboard header shows which feed is live. Market Forge reads prices through
Alpaca; other market data providers are not wired in.

## Feature-to-dependency map

| You want... | You need |
| --- | --- |
| Catalyst radar, charts, manual trading | Python + the pip install + Alpaca paper keys |
| Scored signal-vs-noise catalysts | An AI coding agent (Claude Code, Codex, ...) |
| The copilot: chat, panels, replay | An AI coding agent (Claude Code, Codex, ...) |
| Talking to the desk | Chrome or Edge, or Voicebox for offline voice input |
| A natural-sounding voice back | [Voicebox](https://voicebox.sh/) with a Kokoro profile |
| Alerts on your phone | Discord webhook |
| Auto-entries (paper or live) | An AI coding agent for scoring, then flags in `bot/.env` |

## System notes

- **Windows, macOS, and Linux** all work. Windows has a double-click launcher
  (`run-portable.bat`); other platforms run `MF_EMBEDDED=1 python app.py`.
- **The desk runs while it is open.** Scans fire at 10am, noon, 2pm, and 4pm ET on
  weekdays while the app is running. It is a desk tool, not a headless server. Leave
  it running during market hours.
- **NYSE equities only**, and the market clock has no holiday calendar.
